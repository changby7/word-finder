# 단어 찾기 도우미

> 대화 중 혀끝에서 맴돌기만 하고 떠오르지 않는 단어를, **음성으로 설명하면 적확한 단어 후보 3~5개**를 찾아주는 모바일 웹앱입니다. "설단 현상"으로 대화가 막히지 않게 돕습니다.

**🌐 배포 데모: https://word-finder-changby7.vercel.app** (접속 시 로그인 필요 · 휴대폰 Chrome 권장)

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| **음성 설명 → 단어 후보 찾기** | 마이크로 "○○할 때 쓰는 말…" 하고 설명하면 후보 **3~5개**(한국어·영어)를 한 줄 뜻·언어 배지와 함께 제시 |
| **뜻·예문·유의어 상세 보기** | 후보를 고르면 정확한 뜻 + 예문 1~2개 + 유의어 2~3개 |
| **지어내지 않음** | 확실하지 않은 인명·사실은 만들지 않고 **"확실하지 않음"** 표시. 시사·인물은 **웹검색으로 확인된 것만** 답하고, 확인 불가하면 후보를 비우고 이유를 안내 |
| **음성만으로 완료** | 타이핑 없이 마이크→후보→상세. 마이크 불가 시 타이핑 대체, 설명창에서 **Enter로 바로 찾기** |

## 🖥 화면 구성
1. **메인** — 큰 마이크 버튼 · 인식된 설명 텍스트(수정 가능) · 상태 표시 · (대체) 타이핑
2. **후보 목록** — 카드 3~5개(단어 + 한 줄 뜻 + 한/영 배지 + '확실하지 않음')
3. **상세** — 뜻 · 예문 1~2개 · 유의어 2~3개

## 🔄 이용 흐름
```
마이크 눌러 음성으로 설명 → 텍스트로 변환·수정 → 단어 후보 3~5개
   → (없으면 설명 보태 다시 찾기) → 후보 선택 → 뜻·예문·유의어 상세
```

## 🛠 기술 스택 · 아키텍처
| 영역 | 선택 |
|------|------|
| 화면 | HTML / CSS / JavaScript + 브라우저 음성인식(**Web Speech API**) |
| 백엔드 | **키 보호용 최소 중계 서버**(Flask, 설계 옵션 B) |
| AI 모델 | OpenAI **`gpt-4o`** (+ 시사·인물 질문 시 **웹검색**) |
| 배포 | Vercel (서버리스) — `vercel.json` + `api/index.py` |
| 대상 | 모바일 우선 · 본인 1인용 |

```
[브라우저: 음성인식·화면] ──설명──▶ [중계 서버(키 은닉, Flask)] ──▶ [OpenAI gpt-4o (+웹검색)]
        ▲                                                              │
        └──────────────────────── 후보 / 상세 ──────────────────────────┘
```
> **옵션 B의 핵심:** 순수 브라우저 앱은 AI 키가 코드에 노출됩니다. 그래서 키를 **서버에만** 두는 작은 중계 서버를 통해 AI를 호출합니다.

## 📁 폴더 구조

```
templates/index.html   화면(메인·후보·상세, 음성인식)
requirements.txt  의존성(flask, python-dotenv, openai)
PRD2.md · PLAN.md · DESIGN.md · CHECK.md · CLAUDE.md   기획·설계·검증·규칙 문서
```

## 🚀 로컬 실행
1. Python 3.12 설치 → `pip install -r requirements.txt`
2. `.env.example`을 복사해 `.env` 생성 후 키 입력
   ```
   OPENAI_API_KEY=sk-...본인 키...
   # (선택) 접근 비밀번호
   # APP_USER=admin
   # APP_PASSWORD=원하는-비밀번호
   ```
3. `python server.py` (Windows는 `실행.bat` 더블클릭도 가능) → **http://127.0.0.1:5001**
   - 마이크(음성인식)는 Chrome 권장

## ☁️ Vercel 배포
이 저장소에는 배포 설정(`vercel.json`, `api/index.py`)이 포함돼 있습니다.
1. 저장소를 [Vercel](https://vercel.com)에서 **Import**
2. **Settings → Environment Variables** 에 등록 (코드·저장소엔 키를 넣지 않습니다)
   - `OPENAI_API_KEY` = 본인 OpenAI 키
   - (권장) `APP_USER` = `admin`, `APP_PASSWORD` = 강한 비밀번호
3. **Deploy** → 발급된 `https://...vercel.app` 주소로 접속 (마이크는 HTTPS에서 동작 → Chrome 권장)

> ⚠️ **배포 비용 주의:** 공개 주소로 검색이 실행되면 본인 OpenAI 크레딧이 소모됩니다. `APP_PASSWORD`로 접근을 잠그고, OpenAI 대시보드에서 **월 사용 한도**를 꼭 설정하세요. Vercel 무료 요금제는 함수 실행 시간 제한이 있어, 웹검색이 오래 걸리는 질문은 시간 초과될 수 있습니다.

## 🔒 보안 · 개인정보
- **`.env`는 절대 커밋하지 않습니다**(`.gitignore`에 등록). 배포 키는 Vercel 환경변수로만 관리하세요.
- 옵션 B로 **AI 키가 브라우저에 노출되지 않습니다.**
- 음성·설명은 서버에 저장하지 않습니다. 다만 브라우저 음성인식은 외부 서비스로 전송될 수 있어, 민감한 개인정보는 말하지 않도록 안내합니다.
- 공개 대비 장치: 디버그 기본 꺼짐, 레이트리밋, 입력 길이 제한, 보안 헤더, 호출 제한 시간, 접근 비밀번호(HTTP Basic).

## 🎯 성공 기준 (실측)
- 후보 표시: **일반 단어 5초 이내**(실측 ~3.7초) / 웹검색 필요 시 15초 이내(실측 ~11초)
- 한 번에 **3~5개** 후보 + 각 한 줄 뜻 · 한/영 · 음성만으로 완료 가능
